# Security Policy

## Reporting a Vulnerability

Please do not open public issues for suspected security vulnerabilities.

Report security issues through GitHub's private vulnerability reporting for
this repository when available. If that is not available, contact Unraid
support and include:

- Affected scripts, workflows, or generated artifacts
- Reproduction steps
- Expected impact
- Any relevant logs, checksums, or release artifact names

We will review reports and coordinate fixes before public disclosure.

## Public Release Notes

Before changing this repository to public visibility, run a full-history
secret scan and review release assets for bundled proprietary or sensitive
content.
